# AquaPulse Smart Water Pipeline Monitoring System

This project uses Arduino and sensors to detect water leakage in pipelines using a Digital Twin approach.

## Components Used
- Arduino Uno
- Flow Sensor
- Water Level Sensor
- Water Pump
- LEDs

## Software Used
- Arduino IDE
- Python
- PySerial
- Matplotlib

## Working
The sensors collect water flow data and send it to Arduino. Arduino transfers the data to Python,
where the Digital Twin visualizes the system and detects leakage conditions.
